AI Agent Observability in Production

Production agents fail silently until you instrument them. This post covers the minimum viable observability stack for AI agents: traces, metrics, guardrails, and cost control.

1. Traces

Instrument every tool call and model request. Capture prompt, response, latency, tokens, and tool name. Aggregate into spans.

span = {
  "agent": "support",
  "tool": "search_kb",
  "prompt_hash": "abc123",
  "latency_ms": 184,
  "tokens_in": 642,
  "tokens_out": 118,
  "ok": true
}

2. Metrics

Track task success rate, p95 latency, retry rate, and cost per task. Alert when success rate drops below threshold.

3. Guardrails

Add input/output validators, max tool-call depth, and budget caps. Fail fast with structured errors instead of silent degradation.

4. Cost control

Route prompts by complexity, cache frequent queries, and summarize histories. Small changes often cut costs 30–60%.
