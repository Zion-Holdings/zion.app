Zion Verification Checklist

Use this checklist to verify that all Composio connections, Stripe billing, Calendly bookings, WhatsApp, Resend, and site deployment are working.

1. GitHub Pages

  • Settings → Pages → Source = main
  • Site URL: https://ziontechgroup.com
  • All monetization pages return 200

2. Composio Connections

  • All 15 apps show ACTIVE in Composio dashboard
  • Connection IDs added to GitHub Secrets
  • composio-full-stack.yml runs without errors

3. Stripe Billing

  • Products created: Starter, Growth, Enterprise
  • Price IDs added to GitHub Secrets
  • composio-stripe-create-payment-links.yml generated links
  • Payment flow: /pricing/ → Stripe → /payment-success/

4. Calendly Bookings

  • Event types created: AI Discovery Call, SOC Readiness Review
  • Booking links embedded in site pages
  • Stripe payments enabled for paid events

5. WhatsApp & Resend

  • WhatsApp Business number verified
  • Resend domain verified
  • Test message sent successfully
  • Notification workflows running

6. Revenue Automation

  • composio-calendly-whatsapp-stripe-revenue.yml running on schedule
  • composio-hubspot-lead-monetization.yml syncing deals
  • composio-resend-billing.yml sending invoices
  • Dashboard updated: docs/revenue-dashboard.md

7. SEO Content

  • All monetization pages return 200
  • Internal links working
  • JSON-LD schemas present
  • Sitemap updated

Run this checklist after completing setup. Fix any red items before going live.
