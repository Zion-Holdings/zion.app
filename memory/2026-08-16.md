# 2026-08-16 — Build Config Fix + Build Wrapper Path Fix

## Context
Working on `hero-carousel` branch. Repo is a Next.js 15.5.18 static export with 89K+ service pages via SSG.

## What Was Done
1. **Fixed invalid `--webpack` flag in package.json**: `next build --webpack` fails on Next.js 15.5.18 (flag removed in v15; only available in v16+). Changed `build`, `build:win` scripts to use plain `next build`.
2. **Updated build-wrapper.cjs**: 
   - Increased `NODE_OPTIONS=--max-old-space-size` from 4096 → 8192 for CI (4GB OOMs on 89K+ pages)
   - Fixed candidate binary paths: removed `node_modules/next/dist/bin/next.js` (doesn't exist), corrected to `node_modules/next/dist/bin/next` (no `.js` extension — Next.js 15 moved the binary)
3. **Added tsconfig.typecheck.json**: Targeted config excluding `app/services/*/` for fast local type-checking. Full `tsc --noEmit` OOMs locally with 4GB heap.

## Root Cause of `docs-fallback` build state
Previous `build-state.json` showed `phase: docs-fallback` because build-wrapper tried `node_modules/next/dist/bin/next.js` which doesn't exist. The actual binary is `node_modules/next/dist/bin/next` (no `.js`).

## Verified
- Next.js 15.5.18 has NO `--webpack` flag (confirmed via `next build --help`)
- Binary path confirmed: `node_modules/.bin/next -> ../next/dist/bin/next`
- `package.json` build scripts now use `next build` (no invalid flags)
- Working tree was clean before changes (no cron churn observed)
- All commits pushed to `origin/hero-carousel`
