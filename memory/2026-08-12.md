## Deployment Notes
- type-check and lint crash with OOM (100K+ page project) — `next.config.js` has `ignoreBuildErrors: true` and `ignoreDuringBuilds: true` so builds proceed
- GH Actions workflow triggers on push to main → auto-deploys to gh-pages
- The `_redirects` file (90K lines, 6MB) is the primary fix for 404s
- Waiting for CI to rebuild and deploy to GitHub Pages

## Lessons Learned
- Sitemap must be generated from actual built files, not from source data
- `generateStaticParams` with 45K entries will cause build timeouts — redirects are the scalable fix
- Large `_redirects` files (90K lines) work on GitHub Pages but cause slow git operations
