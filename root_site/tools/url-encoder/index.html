URL Encoder / Decoder

Encode and decode URLs in real time — handles special characters, spaces, and Unicode.

How It Works

  • encodeURIComponent — Encodes all characters except A-Z a-z 0-9 - _ . ! ~ * ' ( )
  • encodeURI — Encodes only characters that are not valid in a URI (preserves : / ? # etc.)
  • decodeURIComponent — Reverses encodeURIComponent, restoring the original string

All encoding/decoding runs locally in your browser. No data is sent to any server.
