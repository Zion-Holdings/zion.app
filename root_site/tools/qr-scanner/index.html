About QR Code Scanning

  • How it works — The image is processed entirely in your browser using JavaScript. No data is sent to any server.
  • Best results — Use clear, high-contrast QR code images with minimal blur or distortion.
  • Supported formats — PNG, JPG, GIF, WebP, and BMP image formats are supported.
  • Privacy — Your images never leave your device. All decoding happens locally.

Powered by jsQR — a pure JavaScript QR code reading library.

Tips for Best Results

  • Ensure the QR code is well-lit and in focus
  • Avoid shadows or glare on the QR code
  • Include some white space (quiet zone) around the QR code
  • Use the highest resolution image available
  • For screenshots, use the original resolution
