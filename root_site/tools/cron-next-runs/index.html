    Syntax reference

    SyntaxMeaning
    *Every value
    */15Every 15th value (0, 15, 30, 45)
    1-5Range, 1 through 5 inclusive
    9-17/2Every 2nd value within 9–17
    1,15,30A specific list of values
    MON / JANDay and month names (case-insensitive)
    0 or 7Both mean Sunday in day-of-week

    Field ranges: minute 0–59, hour 0–23, day-of-month 1–31, month 1–12, day-of-week 0–7. When both day-of-month and day-of-week are restricted, cron fires when either matches (POSIX OR behaviour) — 0 0 1 * MON means the 1st of the month or any Monday. Everything is computed locally in your browser; no data leaves the page.
