How It Works

Hermes Agent runs as a persistent process — either locally on your machine (CLI/TUI), in the cloud via the gateway, or embedded in the Electron desktop app. You interact via messaging platforms (Telegram, Discord, Slack) or directly through the terminal. Agents receive tasks, execute them autonomously using their full toolset, and report back with results.

The platform supports role-based agents: leaf workers that execute focused tasks, and orchestrators that can spawn their own sub-agents for parallel work. Everything is configurable via YAML — models, providers, toolsets, memory backends, security policies, and delivery targets.
