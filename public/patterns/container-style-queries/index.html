Container style queries

Nao e largura. O filho pergunta o valor de uma custom property no container: @container card style(--emphasis: high).

  • data-tone="offer|muted" define --tone
  • data-density="compact" define --density
  • data-emphasis="high" define --emphasis

Browsers sem style query ainda veem o visual via os mesmos data-* (fallback no CSS).
