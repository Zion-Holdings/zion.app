Container style queries

O filho le custom properties do container. Nao e media query: dois cards na mesma viewport podem divergir so pelo token.

Sintaxe

@container card style(--tone: offer) { ... }
@container card style(--featured: true) { ... }
@container card (min-width: 280px) and style(--emphasis: high) { ... }
  • style(--prop: value) compara o valor computado (identificador, nao string entre aspas)
  • Booleano: --featured: true + style(--featured: true)
  • Pode misturar size e style no mesmo @container com and
  • A regra estiliza descendentes, nao o proprio container
