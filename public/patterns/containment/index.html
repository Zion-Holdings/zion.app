CSS containment

container-type ja aplica size containment para queries. contain e content-visibility isolam layout/paint para o browser nao recalcular a pagina inteira.

Propriedades

ValorO que isolaUso no Zion
contain: layoutFilhos nao empurram o layout de foracard
contain: paintClip + stacking; overflow nao vazacard
contain: stylecounters / quotes nao vazamcard
contain: inline-sizeLargura independente do conteudovia container-type
contain: size / strictTambem a altura; precisa de altura conhecidaso demo .ztg-contain-strict
contain: contentlayout + paint + style.ztg-contain-content
content-visibility: autoPula render offscreen.ztg-cq-defer
contain-intrinsic-sizePlaceholder de altura para o scroll nao pularauto 220px

Nao usar em

  • Header sticky — paint/strict quebra position: sticky
  • Dropdown do menu — paint clipa o painel
  • Box sem altura se usar size — colapsa para 0

Cards com layout+paint+style

contain no card

Ja no shell. Mudanca interna nao suja o grid vizinho.

contain: content

Atalho layout paint style, sem size.

contain: strict

Size incluso. Altura via intrinsic 160px.
