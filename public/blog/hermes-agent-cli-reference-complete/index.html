Hermes Agent CLI Reference — Complete Command Guide

The Hermes CLI is the command-line interface for managing autonomous AI agents. From installation to advanced orchestration, these commands cover everything.

Core Commands

hermes              # Interactive chat
hermes setup        # Interactive wizard
hermes model        # Pick/change model
hermes tools        # Enable/disable toolsets
hermes doctor       # Health check
hermes status       # Component status

Cron Jobs

hermes cron list    # List scheduled jobs
hermes cron create "30m"  # Create job
hermes cron run ID  # Trigger now
hermes cron remove ID  # Delete job

Skills

hermes skills list  # List installed skills
hermes skills browse  # Browse hub skills
hermes skills install ID  # Install skill
hermes skills update  # Update outdated skills

MCP Servers

hermes mcp list     # List MCP servers
hermes mcp add NAME --url URL  # Add server
hermes mcp test NAME  # Test connection

Profiles

hermes profile list  # List profiles
hermes profile create NAME  # Create profile
hermes profile use NAME  # Switch profile
