Hermes Agent is an open, extensible AI agent framework by Nous Research that runs in your terminal, messaging platforms, and IDEs. Unlike single-purpose assistants, Hermes operates on a closed learning loop — every interaction improves future performance through self-improving skills, persistent memory, and multi-agent coordination.

What Makes Hermes Different

Most AI agent frameworks reset context every session. Hermes accumulates knowledge: skills, memory, and context across sessions, platforms, and projects.

Key Capabilities

  • 350+ self-improving skills — workflows saved as portable, shareable procedure documents
  • Persistent memory — cross-session, cross-platform memory that accumulates over time
  • 20+ platform gateway — Telegram, Discord, Slack, WhatsApp, Signal, Email, and more
  • Multi-model providers — 20+ LLM providers with automatic failover
  • MCP integration — connect to 6,000+ MCP servers
  • Bot Mode — named specialist bots with @mentions and group chat collaboration
