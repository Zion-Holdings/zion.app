UUID Generator

Generate universally unique identifiers (UUID v4) instantly.

About UUID v4

  • Version 4 — Randomly generated UUIDs using cryptographic randomness.
  • Uniqueness — 2^122 possible values make collisions practically impossible.
  • Format — 36 characters: 8-4-4-4-12 hexadecimal digits (e.g., xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx).
  • Privacy — Generated locally in your browser using crypto.getRandomValues(). Never stored or transmitted.

Use UUIDs for database keys, session tokens, API identifiers, and distributed systems.
