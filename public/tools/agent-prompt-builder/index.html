Agent Prompt Builder

Construct well-structured prompts for autonomous AI agents. Define the role, the task, the constraints, the output format, and the context — then export a prompt ready to use.

Prompt structure

Define who the agent is and what it knows.

Describe what the agent should do, clearly and specifically.

Set the boundaries — what the agent should and should not do.

Define exactly how the agent should structure its response.

Give the agent a concrete example of the expected behavior.

Example assembled prompt
You are an expert technical writer specializing in AI and automation for enterprise IT. Your job is to analyze incoming email and produce a structured classification with intent, priority, and suggested response approach. Constraints: classify into one of five intent categories only. If the email is ambiguous, flag it rather than forcing a classification. Do not invent facts not present in the email. Output format: a JSON object with fields: intent (string), priority (low/medium/high), reasoning (brief string), suggested_action (string). Example: Email = "Can we get a quote for AI observability?" → Intent = "sales_inquiry", Priority = "medium", Action = "route to sales, draft quote response"
