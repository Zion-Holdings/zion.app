About Password Security

  • Entropy — Each character added exponentially increases cracking time.
  • Length vs Complexity — A 20-char lowercase password can be stronger than a 10-char mixed one.
  • Generation — Uses crypto.getRandomValues() for cryptographically secure randomness.
  • Privacy — Passwords are generated locally and never transmitted or stored.

Use a password manager to store generated passwords securely.
