Phishing Analyzer

Lightweight phishing signal checker. Use this checklist to evaluate suspicious URLs and emails before interacting.

URL Signals

✓ Check the domain — look for misspellings, extra subdomains, or unexpected TLDs
✓ Hover over links before clicking — the real destination appears in the status bar
✓ Watch for URL shorteners hiding the final destination
✓ Be suspicious of urgent or threatening language in the message
Talk to Security Team

Email Signals

✓ Verify the sender's address matches the claimed organization
✓ Watch for generic greetings like "Dear Customer" instead of your name
✓ Be cautious with attachments — especially .exe, .zip, or macro-enabled documents
✓ Question requests for credentials, payments, or personal data via email

What to Do

→ Don't click suspicious links or download attachments
→ Report the message to your IT or security team
→ Forward phishing emails to report-phishing@ziontechgroup.com
→ Delete the message after reporting
