What this tool checks

  • Connectivity: whether the endpoint is reachable and responding.
  • Protocol handshake: whether the MCP negotiation completes successfully.
  • Tool inventory: what tools the server exposes and what their schemas look like.
  • Resource inventory: what resources the server makes available.
  • Permission behavior: whether the server enforces expected access controls.
