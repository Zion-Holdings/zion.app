How It Works

  • HEX — Hexadecimal notation (#RRGGBB) used in CSS and design tools.
  • RGB — Red, Green, Blue channels (0–255 each) for screen display.
  • HSL — Hue (0–360), Saturation (0–100%), Lightness (0–100%) for intuitive color picking.
