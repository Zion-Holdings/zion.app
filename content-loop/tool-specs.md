# Tool Specs — Zion Tech Group Free Tools

## 1) AI Prompt Cost Estimator
- Path: `public/tools/ai-prompt-cost-estimator/index.html`
- Behavior: estimate LLM token cost from prompt text + model pricing table.
- Inputs: prompt text, model selector, optional output token estimate.
- Output: token count, estimated input cost, estimated total cost, USD.
- SEO title: `AI Prompt Cost Estimator | Zion Tech Group`
- SEO description: `Estimate LLM prompt cost by token count and model pricing.`

## 2) API Latency Benchmark
- Path: `public/tools/api-latency-benchmark/index.html`
- Behavior: measure latency for user-provided HTTP endpoints.
- Inputs: URL list, method, optional headers.
- Output: min/max/median latency, success/failure count, basic chart.
- SEO title: `API Latency Benchmark | Zion Tech Group`
- SEO description: `Benchmark HTTP endpoint latency and availability.`

## 3) MCP Server Health Check
- Path: `public/tools/mcp-server-health-check/index.html`
- Behavior: validate MCP server reachability and basic tool discovery.
- Inputs: MCP endpoint/transport details.
- Output: reachability status, discovered tools count, error summary.
- SEO title: `MCP Server Health Check | Zion Tech Group`
- SEO description: `Check MCP server health and tool discovery status.`

## 4) Cloud TCO Calculator
- Path: `public/tools/cloud-tco-calculator/index.html`
- Behavior: compute 3-year total cost of ownership from cloud usage inputs.
- Inputs: compute/storage/network units, egress, support tier, discount assumptions.
- Output: monthly/annual TCO, 3-year projection, breakdown by category.
- SEO title: `Cloud TCO Calculator | Zion Tech Group`
- SEO description: `Estimate 3-year cloud total cost of ownership.`

## 5) AI Model Comparison
- Path: `public/tools/ai-model-comparison/index.html`
- Behavior: compare cost/latency/context across popular models.
- Inputs: model set selector, token mix, throughput target.
- Output: ranked comparison table, recommended model, cost delta.
- SEO title: `AI Model Comparison | Zion Tech Group`
- SEO description: `Compare AI model cost, latency, and context limits.`
